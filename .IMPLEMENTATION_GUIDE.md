### 3. Update Mosquitto Configuration

**File: `infra/mosquitto/mosquitto.conf`** - Update/add:

```
# TLS Configuration
listener 8883
protocol mqtt
cafile /etc/mosquitto/ca.crt
certfile /etc/mosquitto/server.crt
keyfile /etc/mosquitto/server.key
tls_version tlsv1_2

# Authentication
allow_anonymous false
password_file /etc/mosquitto/passwd

# ACL (Access Control List)
acl_file /etc/mosquitto/aclfile

# Persistence
persistence true
persistence_location /mosquitto/data/

# Logging
log_dest file /mosquitto/log/mosquitto.log
log_dest stdout
log_type all
```

**File: `infra/mosquitto/aclfile`** (NEW)

```
# Device ACL - each device can only publish to its own topic
pattern write smartrh/devices/%c/*
```

### 4. Generate SSL Certificates

```bash
cd infra/mosquitto/

# Generate CA
openssl genrsa -out ca.key 2048
openssl req -new -x509 -days 365 -key ca.key -out ca.crt

# Generate Server Cert
openssl genrsa -out server.key 2048
openssl req -new -key server.key -out server.csr
openssl x509 -req -in server.csr -CA ca.crt -CAkey ca.key -CAcreateserial -out server.crt -days 365

# Mount in docker-compose.yml:
# volumes:
#   - ./infra/mosquitto/ca.crt:/etc/mosquitto/ca.crt
#   - ./infra/mosquitto/server.crt:/etc/mosquitto/server.crt
#   - ./infra/mosquitto/server.key:/etc/mosquitto/server.key
```
