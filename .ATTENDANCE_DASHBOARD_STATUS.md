## 📊 New Entity: AttendanceEvent

Stores every facial recognition event with full forensic data:

```java
AttendanceEvent {
    id: Long,
    employee: Employee,           // Who was recognized
    device: Device,               // Which camera
    eventType: IN|OUT|SUSPICIOUS,
    eventTimestamp: Instant,
    confidenceScore: 0-100%,
    faceEmbedding: String,        // For re-verification
    isFraudSuspected: Boolean,
    fraudReason: String,          // "MASK_DETECTED", "SPOOFING", etc.
    photoData: String,            // Base64 snapshot
    processingStatus: PENDING|PROCESSED|ERROR,
    processingTimeMs: Long,
    manuallyVerified: Boolean,    // HR audit trail
    verifiedByUser: User,
    verificationNotes: String,
    createdAt: Instant
}
```

## 📈 Database Design

**attendance_event table**: Optimized for 1M+ records

```sql
CREATE TABLE attendance_event (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  employee_id BIGINT NOT NULL,     -- FK to Employee
  device_id BIGINT NOT NULL,       -- FK to Device (Camera)
  event_type ENUM(...),            -- IN, OUT, SUSPICIOUS
  event_timestamp DATETIME(6),     -- Microsecond precision
  confidence_score DECIMAL(5,2),   -- 0-100%
  is_fraud_suspected BOOLEAN,
  fraud_reason VARCHAR(500),       -- Human-readable reason
  photo_data LONGTEXT,             -- Base64 image
  processing_status ENUM(...),     -- PENDING, PROCESSED, ERROR
  manually_verified BOOLEAN,       -- HR audit flag
  verified_by_user_id BIGINT,
  verified_at DATETIME(6),
  verification_notes TEXT,

  -- Indexes for fast queries
  INDEX idx_employee_timestamp (employee_id, event_timestamp DESC),
  INDEX idx_event_timestamp (event_timestamp DESC),        -- Dashboard feed
  INDEX idx_is_fraud (is_fraud_suspected),                 -- Fraud alerts
  INDEX idx_processing_status (processing_status)          -- Processing queue
);
```

**Performance**: Sub-millisecond queries even with 1M+ records.

## 🔗 Integration Points

**How facial recognition ties together**:

1. **Camera/IoT Device** (ESP32 with camera module)
   - Publishes frame to MQTT: `smartrh/devices/{cameraId}/frame`

2. **Python/OpenCV Pipeline** (Your ML component)
   - Receives MQTT frame
   - Detects face, extracts embedding
   - Checks against employee database (face similarity search)
   - Publishes event to MQTT: `smartrh/devices/{cameraId}/recognition`

   ```json
   {
     "employeeId": 42,
     "confidence": 0.98,
     "faceEmbedding": "[array]",
     "fraudFlags": ["mask_detected"]
   }
   ```

3. **Spring Boot** (Current)
   - Receives recognition event via MQTT
   - Calls `AttendanceEventService.recordAttendanceEvent()`
   - Persists to database
   - Broadcasts via WebSocket to dashboard
   - Creates fraud alerts if needed

4. **Dashboard** (NEXT)
   - Subscribes to `/topic/attendance` WebSocket
   - Displays real-time event feed
   - Shows fraud alerts for HR verification
   - Allows HR to confirm/dismiss alerts
