## 📋 MQTT Message Format

**Topic Pattern**: `smartrh/devices/{deviceId}/{sensorType}/{readingType}`

**Payload** (JSON):

```json
{
  "deviceId": "device-123",
  "deviceType": "ACCESS_CONTROL|MOTION_SENSOR|DOOR_LOCK|CAMERA",
  "readingType": "swipe|motion|lock_status|heartbeat|error",
  "value": "string|number|boolean",
  "timestamp": "2026-04-20T10:30:00Z",
  "metadata": {
    "location": "Main Entrance",
    "siteId": "site-A",
    "additionalData": {}
  }
}
```

**Example Topics**:

- `smartrh/devices/device-01/access-control/swipe` → Access event
- `smartrh/devices/device-02/motion/detected` → Motion alert
- `smartrh/devices/device-03/health/heartbeat` → Periodic ping
- `smartrh/devices/device-04/health/error` → Error notification

## 📖 Configuration Examples

### Development (H2 in-memory, no MQTT)

```properties
app.mqtt.enabled=false
```

### Development (with MQTT, local Mosquitto)

```properties
app.mqtt.enabled=true
app.mqtt.broker-url=tcp://localhost:1883
app.mqtt.use-tls=false
```

### Production (with TLS/SSL)

```properties
app.mqtt.enabled=true
app.mqtt.broker-url=ssl://mqtt.example.com:8883
app.mqtt.username=smartrh-user
app.mqtt.password=${MQTT_PASSWORD}  # Set via environment variable
app.mqtt.use-tls=true
```

### Docker Environment (via docker-compose.yml)

```yaml
environment:
  - APP_MQTT_ENABLED=true
  - APP_MQTT_BROKER_URL=tcp://mosquitto:1883
  - APP_MQTT_USE_TLS=false
  - APP_MQTT_QOS=1
```
